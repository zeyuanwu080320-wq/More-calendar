More calendar · 使用说明（中文）
English guide: 使用说明_EN.txt
版本 1.0.0

开箱只差两件事，缺一不可：
  A. 填好 DeepSeek API Key —— 见下面「三」
  B. 日历权限选「完整访问」，不能选「仅写入」—— 见下面「四」

一、安装
1. 解压 More calendar.zip。
2. 将 More calendar.app 拖入“应用程序”文件夹。
3. 双击打开。本工具仅在本机运行，不上传图片，不做后台监听。

二、首次打开被 macOS 拦截时
1. 打开“系统设置” → “隐私与安全性”。
2. 在“安全性”区域找到被拦截的 More calendar，点击“仍要打开”。
3. 如仍提示无法打开，可右键 App → “打开”，再确认一次。
4. 本 App 为本地 ad-hoc 签名，未做 Apple 公证；这是本地个人工具的正常现象。

三、配置 DeepSeek API Key
1. 第一次使用需填入你自己的 DeepSeek API Key（不是学校账号密码）。
2. 点击窗口右上角钥匙图标，粘贴 Key，点“保存到 Keychain”。
3. Key 只保存在 macOS Keychain，不写入代码、日志或导出文件，界面不会回显。
4. 如果系统弹出 Keychain 访问提示，请选择“Always Allow / 始终允许”；若仍不可读，重新保存一次 Key。

四、关键：首次写入日历必须授予“完整访问权限”
1. 第一次点击“写入 Apple 日历”时，macOS 会询问日历权限。
2. 必须在弹窗中授予“完整访问权限”，不能只选“仅写入”。
3. 因为本工具需要在写入前检查同一时间段是否已有事件，只有“仅写入”权限无法读取冲突。
4. 如果误选了“仅写入”，App 会禁用写入按钮；请到“系统设置 → 隐私与安全性 → 日历”中改为完整访问，或点界面底部“升级为完整访问”。

五、使用流程与快捷键
1. 左侧粘贴 Outlook 邮件正文，或按 ⌘V 粘贴截图，或拖入 .png / .jpg。
2. 点“解析”，或按 ⌘↩，等待本地 OCR 和 DeepSeek 返回候选事件。
3. 在右侧逐条核对类型、标题、起止时间、全天、地点、原文依据和歧义说明。
4. deadline / appointment / exam 必须确认；普通活动也默认确认。
5. 点“写入 Apple 日历”，或按 ⌘⇧↩。写入按钮禁用时快捷键也不会触发；有冲突时默认跳过，可在卡片中勾选“冲突仍写入”再写入。
6. 底部可导出最近 30 条脱敏日志；日志不包含邮件原文、标题、地点、图片路径、邮箱或学号/身份证/手机号，入库和导出前都会脱敏。
7. 底部“清空日志”会先弹确认，只删除本地 log.jsonl，不删除其他文件。

附：事件会按类型自动写入不同的 Apple 日历，方便在日历里靠颜色区分：

| 类型 | 写入的日历 | 颜色 |
|---|---|---|
| 考试 exam | More Calendar - 考试 | 红 |
| 生日 birthday | More Calendar - 生日 | 紫 |
| 截止 deadline | More Calendar - 截止 | 橙 |
| 预约 appointment | More Calendar - 预约 | 蓝 |
| 活动 / 其他 activity, other | More Calendar - 活动 | 绿 |

- 这些日历在第一次写入对应类型时**自动创建**，都带 `More Calendar - ` 前缀，便于识别，不会动你原有的日历。
- 日历名会跟随界面语言：中文下是「More Calendar - 考试」，切到英文后会改名为「More Calendar - Exam」（需要完整日历权限，失败时不影响使用）。
- 如果系统不允许新建日历（例如权限不足），会**自动回退到默认日历**，并在底部提示。
- 在 App 里删除或批量平移事件不受影响：管理面板按备注标签识别，跨日历依然有效。

六、隐私
- 图片只在本机内存中做 OCR，不长期保存。
- 只把邮件正文和 OCR 文本发送给 DeepSeek；不发送图片文件。
- 日志只记录计数、类型、修改字段名和错误类型。
- 本工具不替用户判断“一定不会漏”，请逐条核对。

七、系统要求
- macOS 15 或更高版本。
- 需要网络访问 DeepSeek API。
- 需要 Apple 日历完整访问权限才能检查冲突并写入。


八、管理由本工具创建的事件
1. 点击窗口右上角的“管理事件”按钮。
2. 页面只显示备注中包含 [SchoolEventInbox-Managed] 或 [Managed by SchoolEventInbox] 的事件，不会显示你手动添加的私人事件。
3. 可单条删除；循环事件（例如生日）删除时会移除未来的发生记录。
4. 勾选多条后，点底部“删除选中”，确认后只删除勾选的这些事件，未勾选的事件不受影响。循环事件同样会删除未来的所有发生记录。
5. “清空所有”会删除本工具创建的全部事件（不只是勾选的），需二次确认，因此日常清理请优先用“删除选中”。
6. 可勾选多条，使用“批量平移”整体移动 +1 小时、-1 小时、+1 天、-1 天、+1 周，或自定义小时/分钟。
7. 循环事件不支持批量平移；有冲突的事件会跳过，并弹出「平移冲突详情」，逐条写明「哪个事件平移后与哪个事件时间重叠」，不会只给一个数字。

九、生日、全天与语言
1. 生日的结束时间会隐藏，并强制为全天；写入 Apple 日历后会设置为每年重复。
2. 开启“全天”时，开始和结束都只显示日期；关闭后恢复时间选择。
3. 点击窗口右上角“中/EN”可切换界面语言；英文界面使用英文按钮和提示。
